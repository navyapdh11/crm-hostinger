# CRM Hostinger: Enterprise Agentic AI Platform

CRM Hostinger is an enterprise-grade agentic platform designed for high-performance quantitative trading and business intelligence. It integrates deep latent reasoning, adaptive routing, and automated root-cause analysis within a unified, design-led interface.

## Core Features
*   **OpenMythos Architecture**: Recurrent-depth transformer for complex latent reasoning.
*   **SMLM-Inspired Router**: Dynamic request routing between Flash and Pro model tiers for optimal compute efficiency.
*   **Engram Memory System**: Constant-time (O(1)) instruction and knowledge retrieval.
*   **ARCA Engine**: Automated Root-Cause Analysis for proactive, self-healing production operations.
*   **BMW Design System**: A high-signal, corporate-automotive UI aesthetic (0px radii, corporate typography).

## Getting Started

### Prerequisites
- Node.js 20+
- Neon Tech PostgreSQL
- Sanity (Optional for CMS)

### Setup
```bash
git clone https://github.com/navyapdh11/crm-hostinger
npm install
# Configure your environment variables in .env.local
vercel link
vercel env add DATABASE_URL
```

### Deployment
The project is configured for Vercel deployment with automated environment injection.
```bash
vercel deploy --prod
```
